    Machine Learning Engineering 开放书籍¶

    这是一套开放的方法论、工具与分步操作说明合集，旨在帮助你顺利完成大语言模型和多模态模型的训练、微调以及它们的推理。

    这是一份适合 LLM/VLM 训练工程师和运维人员的技术资料。也就是说，这里的内容包含大量脚本和可复制粘贴的命令，能让你快速地解决自己的需求。

    这个仓库是我在训练大语言模型（LLM）（以及 VLM）过程中经验的持续汇集（brain dump）；其中的很多诀窍是我在 2022 年训练开源的 BLOOM-176B 模型、2023 年训练多模态的 IDEFICS-80B 模型、以及 2024 年在 Contextual.AI 训练 RAG 模型时积累下来的。

    我整理这些信息主要是为了自己，好让我能迅速找到过去已经研究过并且确实有效的解决方案，但和往常一样，我很乐意把这些笔记分享给更广泛的 ML 社区。

    目录¶

    第 1 部分：洞察

    1. AI 战场工程 - 为了取得成功，你需要了解的知识。

    2. 如何选择云服务商 - 这些问题将让你有能力获得一次成功的算力云服务体验。

    3. 升级 GPU 何时才值得？ - 一个判断 GPU 代际升级是否物有所值的实用框架，并结合真实的 H200 → B200 基准测试完整演算了一遍。

    第 2 部分：硬件

    1. 计算 - 加速卡、CPU、CPU 内存。

    2. 存储 - 本地、分布式和共享文件系统。

    3. 网络 - 节点内和节点间网络。

    第 3 部分：编排

    1. 编排系统 - 管理容器与资源
    2. SLURM - Simple Linux Utility for Resource Management（简单 Linux 资源管理工具）

    第 4 部分：训练

    1. 训练 - 与模型训练相关的指南

    第 5 部分：推理

    1. 推理 - 关于模型推理的洞察

    第 6 部分：开发

    1. 调试与故障排查 - 如何调试简单和困难的问题

    2. 更多调试内容

    3. 测试 - 众多让编写测试变得愉快的技巧与工具

    第 7 部分：杂项

    1. 资源 - LLM/VLM 编年史

    我维护了两个 SKILL.md 文件，你可以用它们来教导你的 AI 智能体：

    • Machine Learning Engineering — 训练并运维大规模机器学习模型。
    • 评估一个 GPU 集群 — 试用节点 / 验收流程：计算、网络和存储，然后输出一份 markdown 报告。

    另请参阅配套技能：The Art of Debugging 和 Stas' Python Cookbook。

    快捷入口¶

    你很可能会经常需要快速找到的内容。

    工具：

    • torch-dist-bench.py - 比 nccl-tests 容易得多的网络吞吐量基准测试方法（旧名为 all_reduce_bench.py）。
    • torch-distributed-gpu-test.py - 一个用于快速测试节点间连通性的工具
    • mamf-finder.py - 测一测你的加速卡实际能跑出多少 TFLOPS。

    指南：

    • 调试 PyTorch 应用程序 - 让挂起或出错的 PyTorch 应用程序恢复正常的快速可复制粘贴方案
    • 面向用户的 Slurm - 一份 Slurm 速查表和技巧
    • 制作微型模型/数据集/分词器
    • LLM/VLM 编年史合集
